# 한글 유니코드 음절 분해와 동적 조사 계산 수학 백서
*(Dynamic Korean Particle Conjugation via Unicode Syllable Decomposition)*

---

## 1. 문제 정의 (Problem Statement)

영문 게임을 한국어로 로컬라이징할 때 가장 큰 장벽 중 하나는 **조사의 가변성(Particle Inflection)**입니다.
영어는 고유명사나 변수가 문장에 들어갈 때 뒤따르는 단어가 변하지 않습니다:
- `Spencer is here.`
- `Nina is here.`
- `Knock is here.`

반면 한국어는 선행 음절의 **받침(종성)** 존재 여부 및 음소 특성에 따라 조사가 달라집니다:
- `스펜서` + `은/는` $\rightarrow$ **`스펜서는`** (받침 없음)
- `니나` + `은/는` $\rightarrow$ **`니나는`** (받침 없음)
- `두드림` + `은/는` $\rightarrow$ **`두드림은`** (받침 'ㅁ' 있음)

게임 엔진 런타임에 `{0}` 또는 `[[Tag]]` 형태로 변수가 주입되는 경우, 정적 번역 파일에 `(은)는`이나 `(이)가`처럼 괄호로 병기하면 번역의 몰입도가 크게 떨어집니다.

현대 표준 한글 유니코드 블록(U+AC00 ~ U+D7A3)은 **초성 19자, 중성 21자, 종성 28자**의 수학적 조합 규칙에 따라 완벽한 선형 배열로 구성되어 있습니다.

## 3. 수학적 유도 공식 (Mathematical Derivation)

한글 음절의 유니코드 코드포인트 $U$는 다음과 같은 3차원 선형 사상으로 계산됩니다:

$$U = \text{0xAC00} + (\text{Lead} \times 21 \times 28) + (\text{Vowel} \times 28) + \text{Coda}$$

이를 역산하여 임의의 한글 문자 $C$에서 종성(받침) 번호 $\text{Coda}$를 구하는 공식은 다음과 같습니다:

1. **음절 인덱스 계산**:
   $$\text{Index} = C - \text{0xAC00}$$

2. **종성(Coda) 번호 추출**:
   $$\text{Coda} = \text{Index} \pmod{28}$$

### 판정 규칙 (Conjugation Rules)
- $\text{Coda} = 0$: **종성 없음 (열린 음절)**
  - 은/는 $\rightarrow$ `는`
  - 이/가 $\rightarrow$ `가`
  - 을/를 $\rightarrow$ `를`
  - 과/와 $\rightarrow$ `와`
  - 으로/로 $\rightarrow$ `로`

- $\text{Coda} \neq 0$: **종성 있음 (닫힌 음절)**
  - 은/는 $\rightarrow$ `은`
  - 이/가 $\rightarrow$ `이`
  - 을/를 $\rightarrow$ `을`
  - 과/와 $\rightarrow$ `과`
  - 으로/로 $\rightarrow$ `으로`

## 4. 특수 예외 처리: 'ㄹ' 받침 규칙 ($\text{Coda} = 8$)

한국어 문법에서 **도구/방향격 조사 `(으)로`**는 종성이 있는 경우 원칙적으로 `으로`를 취하지만, **종성이 'ㄹ'인 경우에는 예외적으로 `로`**를 취합니다:

- `연필` (Coda = 8, 'ㄹ') $\rightarrow$ **`연필로`** (O) / *연필으로* (X)
- `칼` (Coda = 8, 'ㄹ') $\rightarrow$ **`칼로`** (O) / *칼으로* (X)
- `물` (Coda = 8, 'ㄹ') $\rightarrow$ **`물로`** (O) / *물으로* (X)
- `가방` (Coda = 21, 'ㅇ') $\rightarrow$ **`가방으로`** (O)

본 엔진의 `KoreanParticleResolver`는 $\text{Coda} == 8$ 여부를 실시간 검사하여 이 예외를 완벽히 준수합니다.

## 5. 숫자(Digit) 독음 지원

인벤토리 개수나 골드 수량 등 숫자가 조사 앞에 오는 경우:
- `100`(백, 종성 'ㄱ') $\rightarrow$ `100은` / `100으로`
- `7`(칠, 종성 'ㄹ') $\rightarrow$ `7은` / `7로`
- `2`(이, 종성 없음) $\rightarrow$ `2는` / `2로`

엔진은 마지막 글자가 아라비아 숫자(0~9)인 경우, 한국어 독음 체계의 종성 유무(0, 1, 3, 6, 7, 8: 종성 있음)와 'ㄹ' 종성(1, 7, 8)을 분기 처리합니다.
